## 1. 專案概述與目標

### 1.1 產品是什麼

《地球 Online》是一款 **Android** App，把現實生活（打卡、探索、天氣、每日任務、成就）遊戲化，並搭配虛擬夥伴成長。定位為「把現實當 MMORPG 成就系統」的本地優先體驗。

### 1.2 本次封測目的

| 目的 | 說明 |
|------|------|
| **找問題** | 實機崩潰、權限、定位失敗、文字裁切、流程卡住 |
| **驗證核心好玩／可用** | 打卡 → 任務／成就回饋是否清楚 |
| **驗證多語言** | 繁中／英文切換後文案與成就名是否正常 |
| **收集體驗回饋** | 哪裡誤解、哪裡無聊、哪裡想要更多 |

本次封測 **不是** Google Play 正式上架審核，也 **不是** 完整營收／IAP 驗證。

### 1.3 測試版本與時間

| 項目 | 內容 |
|------|------|
| **產品名稱** | 地球 Online（Earth Online） |
| **測試版代號** | MVP Beta／封測版 |
| **App 版本** | 以安裝包顯示為準（專案 package：`com.skps00.earthonline`） |
| **平台** | **僅 Android**（無 iOS） |
| **時間區間** | **不定**（開放式封測；結束時由主辦另行通知） |
| **測試人數目標** | 約 1–3 位受邀測試者（可再擴大） |
| **APK 取得方式** | 由主辦 **WhatsApp 私訊**發送安裝包／連結（見第 3、8 節） |

### 1.4 希望達成的主要目標

**產品／功能目標**

- 完整走通：登入或 Skip → 新手引導 → 打卡 → 每日任務 → 成就／獎盃 → 夥伴 → 設定（主題／語言／備份）
- 確認 **定位打卡** 在真實手機上可用（含權限說明流程）
- 抽樣確認 **自動解鎖** 與 **手動確認** 兩類成就行為符合預期
- 確認繁中／英文切換後，介面與成就名稱大致正確

**商業／策略目標（封測階段）**

- 驗證「打卡＋成就遊戲化」方向是否值得繼續投入正式上架
- 蒐集下版優先修的 bug 與體驗痛點，降低正式上架後差評風險
- **不**以本次封測驗證營收（金幣／內購目前關閉）

## 2. 測試範圍與限制

### 2.1 在測試範圍內（請務必測）

| 區塊 | 內容 |
|------|------|
| 啟動與帳號 | Google 登入 **或** Skip（Skip 即可完成本地測試） |
| 新手引導 | Onboarding 三屏、定位權限說明與授權 |
| 首頁打卡 | GPS 打卡、地址／國家顯示、「今日是否新地點」提示 |
| 每日任務 | 顯示 3 個任務、進度；含拍照任務跳轉相機 |
| 獎盃／成就 | 列表、分類、詳情、手動「我完成了」、解鎖慶祝彈窗 |
| 夥伴 | 寵物狀態、XP、雷達圖等展示 |
| 設定 | 主題、語言、音效、本機備份匯出／匯入、隱私政策連結、清除資料 |
| 穩定度 | 重複打卡、切換語言、開關 App、文字是否被裁切（例如 Close） |

### 2.2 暫不開放或非本次重點（請勿當成缺陷）

| 項目 | 說明 |
|------|------|
| **iOS** | 未提供 |
| **Expo Go** | 不支援；必須安裝我們的 APK／Dev Client |
| **Google Play 商店下載** | 封測透過 APK／內部連結，非商店頁 |
| **內購／金幣商店** | 已隱藏／未接正式 Billing |
| **POI 自動成就**（海灘、博物館、五大洋自動） | 已規劃、**尚未實作**；相關成就請用手動確認 |
| **全機螢幕時間（UsageStats）** | 僅有本 App 狀態類偵測；勿預期與系統用量完整一致 |
| **正式環境 Google OAuth（release SHA-1）** | 部分裝置／建置上登入可能失敗；**可用 Skip** 繼續測 |
| **敘事任務、社群合養、自訂成就** | Phase 3，不在本次範圍 |
| **生產環境（production AAB）上架** | 下一階段 |

### 2.3 已知設計行為（不是 Bug）

- **多數成就**需在獎盃頁開啟詳情，點 **「我完成了」** 誠實確認（人生里程碑類無法自動偵測）。
- **自動成就**僅部分支援（例如打卡數、特定國家／洲、天氣、早鳥、地震、下雪、跨境、換日線、首度出國等）。
- 每日打卡次數有上限（目前設計約每日 10 次）。
- 天氣／地震等依賴網路與第三方資料，不一定當場觸發。
- 時區與 GPS 差異過大時，打卡可能被拒絕（防作弊）；請確認手機時間／時區為自動或與所在地一致。

## 3. 環境與安裝指引

### 3.1 系統需求

| 項目 | 需求 |
|------|------|
| 作業系統 | Android（建議 Android 10+） |
| 網路 | 建議穩定 Wi‑Fi 或行動數據（天氣／地震／可選 Google 登入） |
| 權限 | **定位**（打卡必需）；相機（拍照任務／證據時）；可選通知 |
| 儲存 | 足夠空間安裝 APK 與本機備份 |
| 帳號 | **可不登入**（Skip）；登入需可用的 Google 帳號 |

### 3.2 下載

1. 透過主辦 **WhatsApp** 取得安裝包或下載連結（邀請訊息中會附上）。
2. 檔名／版本請核對 WhatsApp 訊息中的備註（例如 preview 建置日期）。
3. 若連結過期，請 WhatsApp 向主辦索取新包，**勿**自行到不明網站下載。

> 開發者內部自測另有 USB Dev Client 路線，見開發手冊；一般測試者只需安裝 APK。

### 3.3 安裝步驟（Android）

1. 用手機瀏覽器或檔案 App 開啟下載的 `.apk`。
2. 若系統提示「禁止未知來源」：
   - 依畫面引導允許「安裝未知應用程式」（僅限此次來源，如 Chrome／檔案管理）。
3. 點 **安裝** → **開啟**。
4. 桌面應出現 **「地球 Online」** 圖示。

**若曾安裝過舊包名：**  
舊測試版若為 `com.anonymous.earthonline`，請先 **解除安裝舊 App**，再裝新包（新 package：`com.skps00.earthonline`），否則可能更新失敗或資料混亂。

### 3.4 解除安裝

**設定 → 應用程式 → 地球 Online → 解除安裝**  
（或桌面圖示長按 → 解除安裝）

解除安裝會一併移除本機遊戲進度（除非你曾匯出備份檔並自行保存）。

### 3.5 初始設定（第一次開啟）

1. 開啟 App → 可選 **Sign in with Google** 或 **Skip**（建議封測先 Skip，專心測玩法）。
2. 完成 **新手引導** 三屏。
3. 當系統詢問 **定位權限** → 請選 **允許**（打卡核心功能；拒絕則無法正常打卡）。
4. 進入首頁後，建議先到 **設定**：
   - 確認 **語言**（繁中／English）
   - 可選主題（深／淺，視版本而定）
5. （可選）閱讀 **隱私權政策** 連結是否打得開。

**隱私權政策（線上）：**  
https://skps00.github.io/Earth_Online_v2/privacy-policy.html

## 4. 功能亮點與操作指南

### 4.1 打卡（核心）

1. 打開 **首頁（Home）**。
2. 到戶外或可定位處，點 **打卡**。
3. 成功後應看到地點／大致地址，以及今日是否為新地點等提示。
4. 可多次打卡（受每日上限限制）；同一地點今日重複打卡的提示文字可能不同。

**請留意：** 模擬定位／時區造假可能觸發完整性檢查而失敗——請用真實所在地測試。

### 4.2 每日任務

1. 打開 **任務（Quest）** Tab。
2. 應看到約 **3** 個每日任務與進度。
3. 若有 **拍照** 類任務，點任務相關按鈕進入相機，拍攝後返回，確認進度是否增加。

### 4.3 獎盃與成就

1. 打開 **獎盃（Trophies）** Tab。
2. 可依 **分類** 篩選、切換排序。
3. 點任一成就：
   - 未解鎖且為手動型 → 可點 **「我完成了」** → 確認對話框 → 解鎖慶祝。
   - 請誠實回報真實生活事件（本系統信任玩家）。
4. 切換設定中的語言後，回到獎盃頁，確認名稱／描述是否跟著變。

**若成就總數異常偏少：** 到 **設定 → 清除所有資料** 後重走引導，或解除安裝後重裝（會重置進度）。

### 4.4 夥伴

1. 打開 **夥伴（Companion）** Tab。
2. 查看寵物、經驗等是否正常顯示、畫面是否可捲動、文字是否完整。

### 4.5 設定、備份與語言

1. **設定** 中切換語言／主題／音效，確認各頁文案更新。
2. **匯出備份** → 應提示成功（可自行記下檔案位置）。
3. （進階）可再測匯入備份；匯入會覆蓋當前進度，請先匯出。
4. （可選）**雲端同步**：需 Google 登入；若登入失敗，請改用 Skip 並在回饋中註明，勿卡關。

### 4.6 封測想請你特別留意的體驗

- 按鈕／標題 **最後一個字是否被切掉**（例如 Close → Clos）
- 打卡失敗時錯誤訊息是否看得懂
- 成就解鎖與任務完成彈窗是否重疊、能否關閉
- 中英文哪裡翻譯奇怪或仍是「機器英文」

## 7. 測試規範與保密（NDA）

參與本次封測，即表示你同意下列規範（簡明版保密與測試紀律）。若主辦另有簽署紙本／電子 NDA，以該文件為準。

### 7.1 保密

1. **未公開資訊不得外流**：未上架功能、內部 APK 連結、測試帳號、未發布截圖構圖規格、商業計劃等。
2. **禁止**將封測 APK 轉傳給未受邀者，或上傳到公開網盤／論壇。
3. **商店評分／公開評測文章**：封測期間請勿以正式上架產品名義對外發表；封測結束後若公開討論，請先徵得主辦同意。

### 7.2 截圖與錄屏

1. 允許為了 **向主辦回報 bug** 而截圖／錄屏。
2. **請勿**將含精確住址、人臉、證件、聊天內容的畫面發到公開社群。
3. 分享給主辦前，建議模糊門牌與無關個資。

### 7.3 測試資料與帳號

1. 封測進度主要存在 **你的裝置本地**；若使用 Google 登入與雲端同步，部分資料可能上傳至你授權的 Google Drive AppData（以 App 內說明與隱私政策為準）。
2. **正式上架或封測結束後：**
   - 主辦可能請你卸載測試包或清除資料；
   - 本機測試進度 **不保證** 可遷移至正式版；
   - 請勿在封測環境存入不可取代的重要個資。
3. 使用「清除所有資料」或解除安裝即可能 **無法復原** 進度（除非你有自行匯出的備份檔）。

### 7.4 誠實與安全

1. 手動成就請依真實經歷確認；本封測重視體驗與穩定性，而非衝高解鎖數。
2. 測試時請遵守交通與當地法律（例如勿邊開車邊操作；高山／海岸注意安全）。
3. 發現嚴重資安問題（可越權、可讀他人資料等），請 **私下** 聯繫主辦，勿公開貼 POC。

一般回覆時間：約 **3 小時內**（視時區與是否深夜而定；非即時客服） |

### 8.2 FAQ

**Q1：一定要 Google 登入嗎？**  
A：不必。選 **Skip** 即可測試核心玩法。雲端同步才需要登入。

**Q2：為什麼不能用 Expo Go？**  
A：本 App 含原生模組（如 Google 登入、Skia），必須安裝我們提供的 Dev Client／Preview APK。

**Q3：打卡一直失敗？**  
A：請確認已允許定位、在室外或窗邊、關閉模擬定位、手機時間／時區正確。把錯誤碼原文（如 `GPS_DENIED`、`GPS_TZ_MISMATCH`）一併回報。

**Q4：成就很少／不到預期數量？**  
A：試「設定 → 清除所有資料」或重裝。仍異常請回報當時看到的總數與螢幕截圖。

**Q5：為什麼很多成就不能自動完成？**  
A：人生里程碑（畢業、演唱會等）設計為手動誠實確認。海灘／博物館／五大洋等自動偵測尚在規劃、封測版未上。

**Q6：會收費嗎？**  
A：封測 APK **不收費**。正式版未來若有內購會另說明；目前金幣商店未開放。

**Q7：測試完資料會怎樣？**
